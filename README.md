A simple yet well-structured Library Management System built using C# as a console application.
The project demonstrates core Object-Oriented Programming (OOP) concepts through a real-world scenario.

The system supports two types of users:

Librarian

Add books to the library

Remove books from the library

Display all available books

Regular User

View available books

Borrow books from the library

🔹 Key Features

Clear separation of roles (Librarian / User)

Interactive console-based menu

Uses OOP principles such as:

Encapsulation

Abstraction

Object interaction

Clean and readable code structure

Easily extendable (return book, save data to file, database integration)

🔹 Technologies Used

C#

.NET Console Application

Object-Oriented Programming (OOP)

🔹 Purpose

This project was developed as a learning and practice project to strengthen understanding of OOP concepts in C# and to simulate a real-world library system in a simple and effective way.
